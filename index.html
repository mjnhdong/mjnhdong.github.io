Kết nối GitHub

Token chỉ lưu trong trình duyệt của bạn. Tạo Fine-grained token tại GitHub → Settings → Developer settings, cấp quyền Contents: Read and write cho đúng một repo.

Mở khóa token

Nhập mật khẩu bạn đã đặt để giải mã token GitHub trong phiên này.
